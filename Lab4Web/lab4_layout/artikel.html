Catatan singkat seputar HTML dan CSS.

Mengenal HTML

HTML merupakan bahasa markup yang digunakan untuk membentuk struktur halaman web. Elemen seperti heading, paragraf, gambar, tautan, dan form ditulis menggunakan tag HTML.

Mengenal CSS

CSS digunakan untuk mengatur tampilan halaman web, misalnya warna, font, jarak, ukuran, dan posisi elemen. File CSS terpisah dapat dihubungkan ke HTML melalui tag link pada bagian head.
