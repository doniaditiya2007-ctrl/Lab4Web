# Lab4Web - Praktikum 4 CSS Layout

## Isi Folder
- `lab4_box.html`: latihan elemen div, float, warna, padding, dan clear.
- `lab4_layout/home.html`: halaman utama.
- `lab4_layout/artikel.html`: halaman artikel.
- `lab4_layout/about.html`: halaman tentang website.
- `lab4_layout/kontak.html`: halaman form kontak.
- `lab4_layout/style.css`: pengaturan tampilan halaman layout.

## Cara Menjalankan
1. Ekstrak folder `Lab4Web`.
2. Buka folder tersebut di Visual Studio Code.
3. Buka `lab4_box.html`, lalu jalankan di browser untuk melihat latihan box.
4. Buka `lab4_layout/home.html` di browser untuk melihat halaman utama.
5. Gunakan menu navigasi untuk membuka halaman Artikel, About, dan Kontak.

## Ringkasan Praktikum
- HTML digunakan untuk menyusun struktur konten.
- CSS eksternal dihubungkan menggunakan `<link rel="stylesheet" href="style.css">`.
- `float: left` menempatkan elemen berdampingan.
- `clear: left` membuat elemen berikutnya turun melewati elemen yang di-float ke kiri.
- `box-sizing: border-box` membantu ukuran elemen tetap sesuai lebar yang ditentukan.
- `@media` digunakan untuk menyesuaikan tampilan pada layar kecil.
